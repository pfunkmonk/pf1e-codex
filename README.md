# PF1e Codex

A fast, searchable Pathfinder First Edition rules reference published at
`codex.pipsprojects.com`.

The application is static and deploys directly from the repository root on
Netlify. It supports offline use through its service worker and web manifest.

Over 28,000 browsable entries — classes, races, feats, traits, spells, monsters, items,
rules and more — with search, per-category filtering, prev/next paging through any
list, an artwork gallery of nearly 4,000 illustrations, and a set of at-the-table
tools (encounter builder, initiative tracker, treasure and NPC generators, GM screen).

(A few scraped index pages — "1st Level" to "9th Level" — are in the dataset but hidden from
browse and search. Every count the app displays is derived from the same filter, so the nav never
advertises an entry you cannot reach. The live totals are in the API manifest below.)

## JSON API

Everything is also available as read-only JSON — no key, CORS open — at
`https://codex.pipsprojects.com/api/v1/`. Start at [`/api/`](https://codex.pipsprojects.com/api/) for
the documentation, or `/api/v1/index.json` for the manifest (live totals, every bucket and category).

It is static files generated by `tools/gen-api.mjs`; see HANDOFF.md before changing the data.

**Working on this? Read [HANDOFF.md](HANDOFF.md) first.** It covers the deploy rules
(a push to `main` is a live release, and there is no build gate), the three cache
tokens that must be bumped together, how art resolution works, and the data repairs
that have been applied.
